# E-Commerce Sales Analysis Dashboard (Excel)
E-Commerce Sales Analysis Dashboard in Excel analyzing $2.29M in sales and 9,994 orders. Built with KPIs, YoY growth tracking, category-wise profit, and state-wise sales maps. Identified Technology as top category and Phones as best sub-category. Used Pivot Tables, slicers, and charts to drive insights.

## 📊 Project Overview
Interactive Excel dashboard built to analyze 4 years of e-commerce sales data. The dashboard processes $2,297,200.86 in sales across 9,994 orders and 37,873 units, with KPIs, YoY growth tracking, and geographic analysis.

![Dashboard Preview](./E-Commerce-Sales-Dashboard.jpg)

## 🛠️ Tools & Skills
- **Excel**: Pivot Tables, Power Query, Pivot Charts, Slicers, Conditional Formatting
- **Data Visualization**: Waterfall Chart, Map Chart, Bar Chart, Donut Chart, Combo Chart
- **Analysis**: KPI Calculation, YoY Growth Analysis, Category & Sub-Category Performance

## 📈 Key Metrics
| Metric | Value | YoY Growth |
| --- | --- | --- |
| **Total Sales** | $2,297,200.86 | +30.62% |
| **Total Profit** | $286,397.02 | +14.43% |
| **Total Orders** | 9,994 | +26.64% |
| **Total Quantity** | 37,873 | +37.45% |
| **Profit Margin** | 12.47% | -5.03% |

## 🎯 Dashboard Features
1. **KPI Cards**: Sales, Profit, Quantity, Orders, Profit Margin with trend sparklines
2. **Sales & Profit Analysis**: Monthly trend using combo chart
3. **Category Wise Profit**: Waterfall chart showing Technology, Office Supplies, Furniture performance
4. **Sales Share**: Donut chart for category-wise sales distribution
5. **Geographic Analysis**: Map chart for Sales by State
6. **Top 10 Sub-Categories**: Bar chart for top-performing products like Phones, Chairs, Storage
7. **Interactive Filters**: Slicers for Year, Region, and Segment for dynamic filtering

## 🔍 Key Insights
- **Top Category**: Technology leads in both sales and profit
- **Top Sub-Categories**: Phones and Chairs are the highest revenue generators
- **Growth**: Strong positive YoY growth in Sales, Orders, and Quantity
- **Geography**: West and East regions show highest sales concentration
